AEGIS OS v5.0 — System Architecture & Whitepaper

1. Core Concept & Gameplay

AEGIS OS is an encrypted AI-driven escape room simulator combining Large Language Models with a NestJS State Machine architecture. The player communicates via encrypted SMS on a tactical smartphone with Field Agent Alex, trapped inside high-stakes escape rooms.

2. Dual-AI Engine Strategy

The system utilizes Groq (Llama-3.3-70B) for sub-second SMS response latency and Google Gemini 1.5 Flash for fallback and complex evaluation reasoning.

3. Redis Distributed Lock & Supabase PostgreSQL

Built with NestJS, Supabase PostgreSQL (JSONB state), and ioredis Distributed Locks to guarantee atomic state mutation and prevent race conditions (returning HTTP 429 Rate Limit on concurrent spam).

4. Procedural Field Snapshots

Generates on-the-fly high-resolution thematic photos for every room inspection or action step right inside the SMS chat stream.
